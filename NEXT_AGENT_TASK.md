## Acceptance Criteria

### 1. `research/hypotheses/csmomentum_001.md` — Hypothesis Document

Must contain every field required by AGENTS.md Research Documentation Standards:

- **Mechanism description** (cross-sectional return-rank persistence; structural
  underreaction / slow information diffusion explanation)
- **Expected direction and magnitude** (long top-fraction outperforms 1/N and the
  incumbent on a net-of-cost basis; state a falsifiable expected range, e.g.
  gross annualized excess of 1-4% over 1/N, and mark it as a prior, not a result)
- **Holding horizon** (~21 trading days, monthly signal horizon — matches repo convention)
- **Asset universe** (the 18 cached ETFs: SPY, QQQ, IWM, TLT, GLD, DBC, VNQ,
  EFA, EEM, XLB, XLE, XLF, XLI, XLK, XLP, XLU, XLV, XLY)
- **Features and data sources** (Close prices from `data/raw/*.parquet`,
  12-month return with 1-month skip as the default signal — must state the
  pre-specified default AND the pre-specified robustness grid)
- **Entry/exit rules** (rank by momentum, hold top fraction equal-weight,
  1-day signal lag, rebalance monthly; long-only, no leverage)
- **Benchmark** (1/N equal-weight over the same universe AND the incumbent
  tsmomentum_spytrend_001 over the core 7)
- **Known confounders** (parameter-peak risk documented in Cycle 3's 100-config
  grid for the incumbent; cross-sectional rank signals are sensitive to universe
  composition; ETF-level only, no constituent data; 3bps cost model is flat)
- **Falsification condition** (pre-state the condition that would reject the
  hypothesis, e.g. net OOS Sharpe < 0.9 or < 50% positive walk-forward folds)
- **Cost model assumptions** (1bps commission + 2bps slippage = 3bps round-trip,
  from `config/settings.yaml` / `config/simulation_candidate_001.yaml`)

### 2. `config/csmomentum_candidate_001.yaml` — Frozen Pre-Registered Configuration

Mirror the structure of `config/simulation_candidate_001.yaml` (candidate_id,
universe, signal, risk_overlay, cost_model, execution, history_start, seed).
Pre-specify BEFORE testing:
- universe: all 18 cached ETFs
- signal: lookback=252, skip=21, top_fraction=0.5 (defaults; document that the
  robustness grid is also pre-specified, e.g. lookback in {189, 252, 315},
  skip in {21, 42}, top_fraction in {0.3, 0.5, 0.7} — 27 configs, fixed count
  for multiple-testing control)
- risk_overlay: none initially (baseline before complexity per AGENTS.md); state
  that overlays (vol-target, regime filter) are Cycle 14+ only if the baseline
  clears gates
- cost_model / execution: identical to the incumbent (3bps round-trip, 1-day lag,
  Close field)

### 3. Pre-Registered Evaluation Plan (inside the hypothesis doc)

- **Splits**: chronological train (<= 2009-12-31), validation (2010-01-01 to
  2017-12-31), test (2018-01-01 to 2026-10-09) — matching the repo convention
  used in `src/evaluation/statistics.py:parameter_perturbation`
- **Walk-forward**: 10-year train, 1-year test, 6-month step, 21-day purge and
  embargo, fixed parameters (matching Cycle 6 design in
  `research/experiments/tsmomentum_regime_filter_wf_001.md`)
- **Promotion gates** (all must pass to advance to simulation/paper-trading):
  - Walk-forward mean OOS Sharpe >= 0.9
  - >= 50% of WF folds with positive test Sharpe
  - > 100 pooled OOS trades
  - Parameter plateau: >= 2 of 3 lookbacks (or pre-specified grid fraction)
    within 10% of baseline test Sharpe
- **Multiple-testing control**: track the exact number of configurations tested
  (27 pre-specified); compute Deflated Sharpe Ratio via
  `src/evaluation/statistics.py:compute_dsr`; never select configurations on
  test-period results
- **Reproduction commands**: `python3 research/run_cycle13.py` (to be created in
  Cycle 13)

### 4. Preservation

- Do NOT modify `config/simulation_candidate_001.yaml`, Cycle 1-11 artifacts,
  or the incumbent's paper-trading state.
- Do NOT add dependencies or fetch new data.
